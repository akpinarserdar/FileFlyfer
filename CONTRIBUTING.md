# Katkıda bulunma / Contributing

**Türkçe** | [English](#english)

## Türkçe

Hata bildirimleri ve özellik önerileri için GitHub Issues kullanın. Kod değişikliği gönderecekseniz:

1. Depoyu fork'layıp kendi dalınızda çalışın.
2. Değişikliği küçük ve odaklı tutun.
3. macOS ve Swift gereksinimlerini karşılayan bir ortamda `swift build` ve `swift test` çalıştırın.
4. Pull request açıklamasında sorunu, yaptığınız değişikliği ve elle kontrol ettiğiniz noktaları yazın.
5. Kullanıcıya görünen metinleri Türkçe ve İngilizce güncelleyin.

ADB veya dosya sistemi davranışını değiştiren katkılarda komut argümanlarının güvenli kaldığından ve işlemlerin ortak depolama sınırını aşmadığından emin olun. ADB ikilisini veya kişisel cihaz verilerini pull request'e eklemeyin.

## English

Use GitHub Issues to report bugs or suggest features. To submit a code change:

1. Fork the repository and work on your own branch.
2. Keep the change focused.
3. Run `swift build` and `swift test` on a machine that meets the macOS and Swift requirements.
4. In your pull request, describe the problem, the change, and what you checked manually.
5. Update user-facing text in both Turkish and English.

For changes involving ADB or file-system behavior, preserve safe command arguments and keep operations within shared storage. Do not include the ADB binary or personal device data in a pull request.
